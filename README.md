# foo_mouse_gesture_host

Компонент **жестов мыши** для [foobar2000](https://www.foobar2000.org/) v2.0 / v2.1+ (x64 / x86).

Держите правую кнопку мыши и рисуйте жест — компонент распознаёт направление
движения (включая диагонали и длинные цепочки), а также **колесо** и **rocker**-жесты
в стиле Gesturefy, и выполняет привязанную к жесту команду foobar2000:
любую команду главного меню или контекстного меню (плейлист, текущее выделение,
проигрываемый трек).

---

## Возможности

- **Векторный анализ движения** — траектория разбивается на штрихи, каждый штрих
  квантуется в одно из 8 направлений (4 ортогональных + 4 диагональных).
- **Цепочки жестов** — `↑ →`, `↓ ← ↑`, `↖ ↘` и т.п., до 32 звеньев.
- **Диагонали** — `↖ ↗ ↙ ↘` распознаются отдельными звеньями.
- **Терпимость к округлым углам** — после точного 8-направленного разбора
  компонент пробует вариант без переходных диагоналей и независимую проекцию
  на 4 основных направления. Поэтому `↓ → ↑ ←` работает и со скруглёнными
  углами, а точные диагональные привязки сохраняют приоритет.
- **Wheel-жесты** — прокрутка колеса при зажатой правой кнопке: `W↑`, `W↓`,
  поддерживаются и последовательности (`W↑ W↑`).
- **Rocker-жесты** — зажать одну кнопку мыши и кликнуть другой: `R+L` и `L+R`.
- **Любая команда foobar2000** — списки команд строятся динамически через
  `mainmenu_manager` и `contextmenu_manager`, поэтому в привязках доступны
  и команды сторонних компонентов.
- **Страница настроек на чистом Win32 API** (без ATL/WTL/MFC):
  таблица привязок с группировкой (`Gesture`, `Wheel Up`, `Wheel Down`,
  `Rocker`), крестовина направлений, редактор жеста, выбор группы команд,
  команды и места исполнения.
- **Таблица рисуется компонентом**, а не `SysListView32`: в тёмной теме
  foobar2000 встроенный ListView не доставлял `WM_DRAWITEM` странице и строки
  оставались невидимыми. Свой контрол одинаково выглядит в светлой и тёмной
  теме, поддерживает прокрутку, клавиатуру и заголовки групп. Заголовки
  `Gesture` / `Command` / `Place` встроены в таблицу; ширину колонок можно
  менять перетаскиванием их разделителей, а при нехватке места появляется
  горизонтальная прокрутка.
- **Тёмная тема** foobar2000 v2.0+ (`fb2k::coreDarkMode`).
- **Не конфликтует со штатным перетаскиванием треков**: пока зажата ПКМ над
  окном foobar2000, компонент забирает её события себе, поэтому хост не
  запускает своё «перетащить трек правой кнопкой». Обычный правый клик
  (без сдвига) компонент возвращает сам — контекстное меню открывается
  как раньше и без задержки: синтетический клик отправляется из цикла
  сообщений, а не изнутри низкоуровневого хука (иначе система ждёт
  возврата из колбэка и меню открывается с паузой).

## Установка

### Из релиза (рекомендуется)

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте `foo_mouse_gesture_host-<версия>-x64.fb2k-component` для
   64-битного foobar2000 либо `foo_mouse_gesture_host-<версия>-x86.fb2k-component`
   для 32-битного.
3. При необходимости проверьте файл по приложенному `SHA256SUMS.txt`:
   `Get-FileHash .\foo_mouse_gesture_host-<версия>-<архитектура>.fb2k-component -Algorithm SHA256`.
4. Дважды щёлкните по файлу — foobar2000 сам предложит установить компонент,
   либо перетащите его в окно foobar2000.

### Вручную

1. Скачайте `.fb2k-component` нужной архитектуры (это обычный ZIP-архив).
2. Распакуйте `foo_mouse_gesture_host.dll` в папку `components` вашего профиля:
   - установка: `%APPDATA%\foobar2000-v2\components\`
   - portable: `<папка foobar2000>\components\`
3. Перезапустите foobar2000.

Проверить, что компонент загрузился, можно в
**File → Preferences → Components** — там будет строка *Mouse Gesture Host*.

## Использование

1. Откройте **File → Preferences → Tools → Mouse Gesture Host**.
   При первом запуске в таблице уже есть четыре стандартных привязки
   (`←`, `→`, `↑`, `↓`), так что жесты работают сразу.
2. Соберите жест кнопками-стрелками (и кнопками колеса/рокера) либо выберите
   готовую привязку в таблице — тогда её жест подставится в поле **Gesture**.
3. Выберите **Group** (откуда брать команду), **Command** (саму команду)
   и **Place** (в каком контексте её исполнять).
4. Нажмите **Add New** (или **Update** для существующей строки) и затем **Apply**.

Клик по заголовку **Gesture**, **Command** или **Place** переключает сортировку
представления: `▲` → `▼` → нейтральный индикатор. **Group by category** независим
от сортировки: во включённом режиме у каждой непустой категории один заголовок,
а сортировка действует внутри групп; в выключенном режиме строки идут без заголовков
и повторяющихся префиксов, а категорию показывают компактные chips `Dir`, `W↑`,
`W↓`, `R↔`. Подпись **Manual order** означает исходный порядок внутри выбранного
представления. Ни группировка, ни сортировка не меняют порядок исполнения;
**Up/Down** в отсортированном виде сначала возвращают Manual order. Оба режима
просмотра не сохраняются в конфигурации.

Готово: зажмите правую кнопку мыши над окном foobar2000 и нарисуйте жест.

> **Почему Add New может «не работать»:** кнопка активна только когда в поле
> **Gesture** собран жест **и** в списке **Command** выбрана команда. Если
> список пуст, в нём показывается причина: для групп `context(...)` команды
> строятся по текущему выделению, поэтому сначала выделите треки в плейлисте
> (или выберите группу `main menu`).

### Запись жеста

| Кнопка | Значение |
|---|---|
| `↑` `↓` `←` `→` | добавить основное направление |
| `↖` `↗` `↙` `↘` | добавить диагональное направление (`UL` / `UR` / `DL` / `DR`) |
| `BS` | удалить последнее звено |
| `wheel ↑` / `wheel ↓` | добавить звено колеса (`W↑` / `W↓`) |
| `R+L` / `L+R` | добавить rocker-звено |

Каноническая запись жеста (то, что хранится в конфигурации):

| Жест | Запись | Отображение |
|---|---|---|
| вверх | `U` | `↑` |
| вниз | `D` | `↓` |
| влево | `L` | `←` |
| вправо | `R` | `→` |
| влево-вверх | `UL` | `↖` |
| вправо-вверх | `UR` | `↗` |
| влево-вниз | `DL` | `↙` |
| вправо-вниз | `DR` | `↘` |
| колесо вверх | `WU` | `W↑` |
| колесо вниз | `WD` | `W↓` |
| rocker (ПКМ → ЛКМ) | `R+L` | `R+L` |
| rocker (ЛКМ → ПКМ) | `L+R` | `L+R` |

Несколько звеньев разделяются пробелом: `U R`, `U D L`, `WU WU`.
Пробелы между звеньями добавляются кнопками автоматически. Диагональ внутри
одного звена записывается слитно: `UR` (`↗`), а `U R` означает два отдельных
движения `↑`, затем `→`. Например, после `wheel ↑` и кнопки `↗` получится `WU UR`.

### Группы команд (Group)

| Group | Источник |
|---|---|
| `main menu` | главное меню foobar2000 (File / Edit / View / Playback / Library / Help) |
| `context(ui selection)` | контекстное меню текущего выделения |
| `context(playlist)` | контекстное меню активного плейлиста |
| `context(now playing)` | контекстное меню проигрываемого трека |

Содержимое списков **Command** строится в момент открытия страницы, поэтому
там присутствуют и команды сторонних компонентов (Converter, Run services и т.д.).

### Место исполнения (Place)

| Place | Поведение |
|---|---|
| `Main Window` | команда выполняется в общем контексте (главное меню / текущее выделение) |
| `Playlist` | команда выполняется в контексте активного плейлиста |
| `Now Playing` | команда выполняется в контексте проигрываемого трека |

Для команд главного меню `Place` игнорируется.

### Rocker-жесты

**Rocker** — это жест «одна кнопка зажата, второй щёлкаем» (как в Opera/Gesturefy):

| Комбинация | Что делает пользователь | Запись |
|---|---|---|
| `R+L` | зажать **правую** кнопку, затем щёлкнуть **левой** | `R+L` |
| `L+R` | зажать **левую** кнопку, затем щёлкнуть **правой** | `L+R` |

Отпускание второй кнопки выполняет команду. Например, `R+L` удобно
привязать к «Play/Pause», а `L+R` — к «Next».

### Настройки

| Настройка | Описание |
|---|---|
| **Stroke Length** (1..100, по умолчанию 8) | порог срабатывания штриха: `4 + 2 × значение` пикселей (20 px при значении 8). Меньше значение — чувствительнее жесты |
| **Disable mouse gesture** | полностью отключить перехват жестов |
| **Represent direction by the alphabet** | показывать `U/D/L/R` вместо стрелок |
| **Execute only the first command** | при нескольких привязках к одному жесту выполнять только первую |

### Привязки по умолчанию

| Жест | Команда |
|---|---|
| `L` (`←`) | Playback → Previous |
| `R` (`→`) | Playback → Next |
| `U` (`↑`) | Playback → Volume up |
| `D` (`↓`) | Playback → Volume down |

Их можно изменить или удалить на странице настроек, а кнопка **Reset** вернёт
значения по умолчанию.

## Как это работает

```
src/
├── main.cpp                 инициализация компонента, метаданные, initquit
├── binding_index.h/.cpp     immutable snapshot, exact/prefix и wheel-индексы
├── gesture_tokens.h/.cpp    модель звеньев, разбор/форматирование жестов
├── gesture_recognizer.h/.cpp векторный анализ траектории (8 направлений,
│                            диагонали, цепочки, антидрожание)
├── gesture_session.h/.cpp   numeric session, bounded ring и hook health
├── gesture_config.h/.cpp    настройки (cfg_var), backup и флаг первого запуска
├── gesture_config_serialization.cpp  строгая schema v2 и миграция legacy TSV
├── command_catalog.h/.cpp   динамические списки команд и их исполнение
├── gesture_engine.h/.cpp    WH_MOUSE_LL хук, сессия жеста, отложенный запуск
└── preferences_page.h/.cpp  страница настроек (preferences_page_v3 + Win32)
```

Ключевые решения:

- **`WH_MOUSE_LL`** позволяет работать поверх любого UI, не требуя поддержки
  со стороны панелей. Хук принадлежит выделенному `_beginthreadex` потоку с
  собственным message pump; `initquit::on_init`/`on_quit` запускают и останавливают
  его с главного потока.
- **Callback минимален**: numeric session и очередь фиксированной ёмкости (256
  результатов), предпочтительное вытеснение старых move и счётчик потерь.
  Recognizer, строки и `SendInput` выполняются в worker message loop. Команды
  и SDK console остаются на главном потоке через отдельную bounded queue,
  поэтому модальные диалоги и меню не блокируют низкоуровневый callback.
- **Обычный правый клик сохраняется**: ПКМ над главным окном подавляется на
  время возможного жеста, а tap без привязки повторяется парой `SendInput` по
  сохранённым координатам после повторной проверки окна. Собственные события
  помечаются `dwExtraInfo`; эвристика injected + 500 ms не используется.
- **Hook health** проверяется таймером worker-потока: молчание при активности
  мыши запускает reinstall с экспоненциальным backoff и логами. Состояние кнопок
  периодически сверяется с `GetAsyncKeyState`, чтобы завершить сессию после
  пропущенного up-события.
- **Сопоставление идёт от точного к более свободному**: сначала исходная
  8-направленная цепочка, затем цепочка с раскрытыми переходными диагоналями
  и запасная 4-направленная проекция. Поэтому округлость углов не мешает
  составным жестам, но существующая точная диагональная привязка всегда
  выбирается первой.
- **Команды имеют устойчивую идентичность**: SDK 2.0 `menu_tree_item` даёт
  command/subcommand GUID; если GUID нулевой, используется проверяемый путь
  индексов вместе с полным label. Legacy разрешается только по единственному
  полному пути. При unavailable/conflict команда не выполняется, а существующий
  dropdown показывает статус без дополнительных колонок; leaf fallback удалён.
- **Конфигурация читается строго**: legacy TSV мигрирует в `MGH2` при следующем
  Apply, malformed rows получают диагностику, полные дубликаты удаляются с
  приоритетом первой строки. Перед новой записью сохраняется последняя валидная
  таблица; intentionally empty отличается от самого первого запуска.
- **Индексы строятся при reload**, а не в горячем пути: immutable snapshot
  содержит exact map и отсортированный prefix index. Исполнение получает span
  номеров строк, поэтому не копирует bindings и сохраняет их исходный порядок.

## Сборка из исходников

### Требования

- Windows 10/11
- Visual Studio 2022 с рабочей нагрузкой *Desktop development with C++*
- PowerShell 5.1+ (для скачивания SDK)

### Шаги

```powershell
git clone https://github.com/templarundead/foo_mouse_gesture_host.git
cd foo_mouse_gesture_host

# Скачать официальный foobar2000 SDK (2023-09-23) в .\sdk
powershell -ExecutionPolicy Bypass -File tools\fetch-sdk.ps1

# Собрать 64-битную версию (Release | x64)
msbuild foo_mouse_gesture_host.sln /m /p:Configuration=Release /p:Platform=x64

# Собрать 32-битную версию (Release | Win32)
msbuild foo_mouse_gesture_host.sln /m /p:Configuration=Release /p:Platform=Win32
```

Результат:
- x64: `build\x64\Release\foo_mouse_gesture_host.dll`;
- x86: `build\Win32\Release\foo_mouse_gesture_host.dll`.

Можно открыть `foo_mouse_gesture_host.sln` и в Visual Studio — в решении
настроены конфигурации `Debug` / `Release` для платформ `x64` и `Win32`.

Portable-тесты не требуют SDK или запущенного foobar2000:

```powershell
msbuild tests\logic_tests.vcxproj /m /p:Configuration=Release /p:Platform=x64
build\logic-tests\x64\Release\logic_tests.exe --benchmark
# Для Win32 используйте /p:Platform=Win32 и каталог build\logic-tests\Win32\Release.
```

`--benchmark` дополнительно измеряет indexed/linear lookup для 100 и 1000
привязок. Это informational benchmark чистой логики, а не измерение p99
низкоуровневого callback или доказательство отсутствия аллокаций. Portable
тесты также покрывают idle/drag/tap, оба rocker, fractional wheel, overflow
очереди и reinstall/backoff на fake clock.

После изменения Win32 adapter дополнительно нужна ручная проверка в foobar2000:
обычный контекстный клик без паузы, drag без контекстного меню, `R+L`/`L+R`,
`WU`/`WD`/`WU WU` (включая дробные дельты), жесты только над главным окном,
Disable и Apply без перезапуска. CI подтверждает сборку и чистую логику, но не
подменяет эту проверку интеграции с Windows hook.

### Ручная матрица Preferences

Следующие пункты нужно выполнить в foobar2000 на Windows 10/11 после изменения
раскладки страницы. Не отмечайте их по результатам CI: автоматические UI и DPI
проверки в этой матрице не заменены.

| Режим | Обязательная проверка |
|---|---|
| 100%, 125%, 150%, 200% DPI | Внешняя верхняя рамка таблицы совпадает с content edge, не перекрыта и не обрезана; заголовок и первая строка кликабельны. Все 9 целей D-pad не меньше 32 DIP по обеим осям, сетка 3×3 не имеет внутренних разрывов. |
| Каждый DPI, светлая и тёмная тема | Нажать `↖ ↑ ↗`, `← BS →`, `↙ ↓ ↘`, затем wheel и оба rocker: поле Gesture получает правильные звенья, соседние кнопки не перекрываются, внешний интервал перед wheel сохраняется. |
| Изменение размера, minimize/restore, повторное открытие Preferences | `WM_SIZE` и `fit_to_parent` сохраняют раскладку без накопления отступов; таблица продолжает сортироваться и прокручиваться, заголовки и первая строка остаются доступны. |
| Минимальный размер окна и узкая страница | Контролы, **Group by category**, счётчик и **Help** не перекрываются; под таблицей не остаётся пустой постоянный hint-блок. Tooltip ограничен по ширине, переносит текст и остаётся в пределах рабочей области экрана. |
| Tooltip и Help | Навести указатель на каждый D-pad, wheel, rocker, Stroke Length, Add New/Update/Delete, Up/Down и поля формы: текст соответствует контролу и не мигает при движении мыши. Перейти к **Help** клавишей Tab: фокус открывает все четыре строки, включая полные `R+L` и `L+R`; Escape, потеря фокуса и клик вне закрывают справку. При наведении она открывается и закрывается при уходе мыши; в тёмной теме фон и текст остаются тёмными/светлыми соответственно. |
| Group by category и привязки | На заранее перемешанных Gesture/Wheel Up/Wheel Down/Rocker включить группировку: один заголовок на непустую категорию в стабильном порядке, без пустых строк. Переключить все сортировки и направления, затем выключить группировку: плоский список без префиксов, с chips `Dir`/`W↑`/`W↓`/`R↔`. В обоих режимах Edit/Delete/Up/Down и Apply затрагивают выбранную привязку, выделение сохраняется, физический порядок исполнения меняется только Up/Down. |
| Возврат высоты таблице | На одном размере окна сравнить высоту таблицы до/после: пока не сработал `min_list_height`, прирост равен `old_lower_height - new_lower_height`, а нижние контролы не перекрыты. На прежней full-width раскладке это весь hint-блок; если высоту ограничивала левая колонка или clamp минимальной высоты, прирост может быть нулевым — контролы не сжимаются искусственно. |
| Длинный локализованный текст, включая кириллицу | В локализованной сборке tooltip переносится по словам и показывает всю справку, включая `R+L` и `L+R`; `TTS_NOPREFIX` не превращает `&` в mnemonic. Счётчик, **Group by category** и **Help** остаются в своей строке без наложений. |
| Command dropdown | Tooltip не перекрывает раскрытый список и восстанавливается после его закрытия. При перетаскивании ползунка список прокручивается во время `SB_THUMBTRACK`, до отпускания кнопки мыши; выбор и Apply работают как раньше. |

Решение включает в себя проекты SDK (`pfc`, `foobar2000_SDK`,
`foobar2000_component_client`), поэтому **перед первым открытием .sln**
обязательно выполните `tools\fetch-sdk.ps1` — иначе Visual Studio не найдёт
эти проекты. PFC автоматически собирается в конфигурации `Debug FB2K` /
`Release FB2K` (в остальных конфигурациях его `fb2k-hooks` конфликтуют
с `foobar2000_SDK.lib`).

### Параметры проекта

- `PlatformToolset` = `v143`, `LanguageStandard` = `stdcpp20`, `/utf-8`
- Include-пути: `sdk`, `sdk\foobar2000`, `src`
- Линкуются `pfc`, `foobar2000_SDK`, `foobar2000_component_client`
  и предсобранный `shared-x64.lib` / `shared-Win32.lib` из
  `sdk\foobar2000\shared\` (выбирается по платформе сборки)
- `comctl32.lib`, `uxtheme.lib`, `shlwapi.lib` — ListView/UpDown, тёмная тема,
  `StrCmpLogicalW` из состава SDK

## CI и релизы

`.github/workflows/build.yml`:

1. запускается на `windows-latest` при push в `main`, pull request, ручном
   запуске и при push тега `v*`;
2. скачивает **официальный** SDK и распаковывает его только после проверки
   закреплённого SHA-256; при недоступности источника использует GitHub mirror
   с отдельным SHA-256. Незакреплённые Chocolatey-пакеты в сборке не используются;
3. параллельно собирает `Release | x64` и `Release | Win32` через MSBuild;
4. проверяет PE machine каждой DLL (`0x8664` / `0x14C`), упаковывает её в отдельный
   `foo_mouse_gesture_host-<версия>-<x64|x86>.fb2k-component` и загружает
   оба пакета как artifacts;
5. при push тега требует точного совпадения `vX.Y.Z` с
   `MGH_COMPONENT_VERSION`, заново проверяет имена, состав ZIP и PE machine
   ровно двух пакетов, создаёт `SHA256SUMS.txt` и прикрепляет к GitHub Release
   оба `.fb2k-component` и checksums. Права `contents: write` есть только у release-job.

Метка **Latest** на GitHub может указывать на более старый выпуск, пока новый тег
ещё не опубликован: исходники и release-пакеты не считаются одной версией без
описанной выше автоматической проверки.

Чтобы выпустить новую версию:

```powershell
# поднимите версию в src/component_version.h (MGH_COMPONENT_VERSION)
git tag v1.3.1
git push origin v1.3.1
```

### Необязательная ручная подпись выпуска

CI не содержит сертификатов и не подписывает DLL автоматически. Maintainer может
подписать `foo_mouse_gesture_host.dll` своим код-signing сертификатом **до**
упаковки `.fb2k-component`, например через `signtool sign /fd SHA256 /td SHA256
/tr <timestamp-url> ...`. После подписи DLL нужно заново создать ZIP-пакет и
`SHA256SUMS.txt`. Контрольная сумма подтверждает целостность файла, но не заменяет
Authenticode-подпись; неизвестный сертификат не следует считать доверенным.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| Таблица привязок пустая | Пустая таблица после **Apply** считается осознанной настройкой и сохраняется. Стандартные привязки создаются только при самом первом запуске либо явной кнопкой **Reset**. При повреждении конфигурации компонент сначала пробует последнюю валидную резервную копию и пишет диагностику в консоль. |
| Add New не реагирует | Не собран жест (поле **Gesture** пустое) или не выбрана команда — компонент покажет диалог с причиной. Соберите жест стрелками, и кнопка сработает. |
| Список Command пуст для `context(...)` | В плейлисте нет выделенных треков: команды контекстного меню строятся по выделению. |
| Список Command пуст для `main menu` | Главное меню ещё не готово (страница открыта слишком рано) или сторонний компонент сломал перечисление меню. Закройте и откройте страницу; подробности пишутся в консоль foobar2000 (**View → Console**). |
| Часть элементов страницы обрезана | Страница подгоняется под область настроек при показе. Если окно настроек очень маленькое, отступы автоматически сжимаются; увеличьте окно. |
| Жест не срабатывает | Жесты работают только над окном foobar2000; проверьте, что привязка сохранена кнопкой **Apply**, и что не включён **Disable mouse gesture**. Если жест распознался, но привязки к нему нет, в консоль пишется `gesture "..." has no binding` — сравните жест с привязкой в таблице. |
| Жест срабатывает «через раз» или склеивается в диагональ | Уменьшите **Stroke Length** (например, до 5–6). В 1.1.6 добавлен запасной 4-направленный разбор: у `↓ → ↑ ←` могут быть скруглённые углы и необязательный замыкающий поворот, а переходные диагонали не мешают совпадению. |
| Wheel-жест (`W↑`/`W↓`) не срабатывает | Начиная с 1.1.4 дробные дельты высокоразрешённых колёс и тачпадов накапливаются до полного щелчка, поэтому один щелчок = одно звено `W↑`. Проверьте, что привязка сохранена и что курсор над окном foobar2000. |
| Не работает штатное перетаскивание треков правой кнопкой | Так и задумано: пока жесты включены, ПКМ над окном foobar2000 принадлежит компоненту. Отключите **Disable mouse gesture**, чтобы вернуть стандартное поведение. |
| Контекстное меню не открывается | Оно открывается обычным правым кликом (без движения). Если вы сдвинули мышь, компонент считает это жестом; при отсутствии привязки команда не выполняется. |

## Диагностика

Компонент пишет в консоль foobar2000 (**View → Console**) несколько строк —
по ним видно, что происходит:

```
Mouse Gesture Host: 4 gesture bindings, 12 commands in group "main"
Mouse Gesture Host: table rows 5 (items in list: 5), bindings 4
Mouse Gesture Host: added gesture "L" -> Playback/Previous (5 total)
Mouse Gesture Host: gesture "D R U L" has no binding
```

* `table rows` — сколько строк отрисовано в таблице (заголовки групп + привязки);
* `items in list` — сколько строк реально принял ListView;
* `commands in group` — сколько команд вернул `mainmenu_manager`/`contextmenu_manager`;
* `has no binding` — жест распознан, но привязки к нему нет (печатается один раз
  на жест за запуск).

Если `bindings` больше нуля, а таблица визуально пуста — это ошибка отрисовки,
и по этим строкам её видно сразу.

## Ограничения

- Жесты работают только над окном foobar2000 (включая его дочерние окна),
  но не над другими приложениями.
- Если пункт меню переименован (например, при смене языка интерфейса),
  сохранённая привязка перестанет находить команду — выберите команду заново.
- Низкоуровневый хук не действует поверх окон, запущенных с повышенными
  правами (UIPI), если сам foobar2000 запущен без них.
